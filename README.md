# Animated Developer Portfolio

A fully animated, single-page personal portfolio for a blockchain and full-stack developer. It is built with plain HTML, CSS and JavaScript plus a few CDN libraries, with no build step.

## Features

- **Animated background**: a WebGL shooting-star scene (`three.js` with bloom post-processing), a Particles.js star field and drifting CSS clouds behind every section.
- **Hero section with parallax**: the headline shifts and fades as you scroll. The navigation bar becomes sticky after the first 20px.
- **Skills section**: circular "water fill" progress gauges for blockchain, front-end, back-end and mobile skills.
- **Services and "What I can do" cards**: GSAP letter-by-letter titles that animate when scrolled into view, and flip cards listing technologies by area (blockchain, full-stack, DevOps).
- **Previous Works gallery**: an Isotope masonry grid with *All / Blockchain / Website* filters and responsive pagination (12, 10 or 7 items per page depending on screen width). Each tile links to the live project.
- **Certificates**: holographic trading-card style tiles that tilt with the mouse or touch and link to HackerRank certificates.
- **Contact section** with a morphing "Interested? / Contact Me" text effect, mail and Telegram links, and a scroll-to-top button.
- **Lazy-loaded images**: `IntersectionObserver` loads each image and fades it in with GSAP.

## Getting started

No install or build is needed.

1. Clone the repository.
2. Open `index.html` directly in a browser, or serve the folder with any static file server. Examples:

   ```sh
   npx serve .
   # or
   python3 -m http.server 8080
   ```

3. Edit the text, links and images in `index.html` and `assets/` to make it your own.

`404.html` is the standard page generated by the Firebase CLI. It is used if you deploy the folder to Firebase Hosting.

## Project structure

```

├── index.html            The whole site: nav, hero, about, skills, services,
│                         abilities, works gallery, certificates, contact
├── 404.html              Not-found page (Firebase Hosting)
└── assets/
    ├── css/              hero, portfolio, pricing (flip cards), pokermon (holo cards),
    │                     cloud_stars, shootingstar, scrollBtn, w3.css
    ├── js/               hero.js (particles, parallax, sticky nav),
    │                     portfolio.js (lazy load, Isotope filters, GSAP, text morph),
    │                     shootingstar.js (three.js scene), pokemon.js (card tilt),
    │                     scrollBtn.js, pricing.js, threemodel.js
    └── images/           Section backgrounds, avatar, portfolio/ screenshots
```

## Notes and known limitations

- `assets/js/threemodel.js` is not included by `index.html`, and the 3D model it expects (`assets/model/`) is not in the repository.
- The gallery refers to `Axelar.jpg`, but the file is named `Axelar.JPG`. That image will not load on case-sensitive hosts.
- On browsers without `IntersectionObserver`, `portfolio.js` loads a polyfill from `polyfill.io`. That domain is no longer considered safe, so it is better to remove the fallback or host the polyfill yourself.
- `portfolio.js` logs the scroll position to the console on every scroll event.
